# КОД АНТВЕРПЕНА

Детективная онлайн-игра для компании по материалам **реального дела** — ограбление века: Антверпен, февраль 2003 года. Банда «Школа Турина» вскрыла подземное хранилище Алмазного центра с десятью слоями защиты и вынесла более $100 млн в алмазах — без единого срабатывания сигнализации.

- **Экран:** телевизор/большой экран (браузер Samsung Tizen или любой браузер) — карта города, фото, документы, разборы.
- **Управление:** один iPhone (или любой телефон) — досье следователя: ход, улики, ответы, подсказки.
- **Игроки:** 2–8 человек, все вместе — коллективный детектив.
- **Время:** 2–3 часа. Головоломок «на спички» нет — только логика и эрудиция на материалах настоящего дела.

## Быстрый старт: загрузка на GitHub Pages

Нужен только аккаунт GitHub (бесплатный) и git. Запуск на Mac/Linux/Windows (git bash):

```bash
cd kod-antverpena
./deploy.sh
```

Скрипт спросит ник GitHub и имя репозитория, затем:

- если у вас установлен **GitHub CLI** (`gh`, залогинен) — сам создаст репозиторий, включит Pages и напечатает готовый адрес;
- если нет — покажет ссылку `github.com/new` и подскажет два клика для включения Pages (Settings → Pages → Deploy from a branch → `main` / `/ (root)`), затем дождётся публикации и выдаст адрес вида `https://ваш-ник.github.io/kod-antverpena/`.

Повторный запуск `./deploy.sh` обновляет сайт.

## Вечеринка: как запустить

1. **Телевизор.** Откройте браузер Samsung TV (кнопка `INTERNET` / `WWW` на пульте), введите адрес игры. На старте выберите **«ЭКРАН СЛЕДОВАТЕЛЯ»**. На экране появится код комнаты и QR.
2. **Телефон.** Отсканируйте QR камерой iPhone — откроется режим **«ПУЛЬТ СЛЕДОВАТЕЛЯ»** уже привязанный к комнате. Или откройте тот же адрес и введите код вручную.
3. Играйте: читайте вслух, обсуждайте, решайте вместе. Ход игры ведёт тот, у кого телефон в руках.

**Запасные режимы:**

- **СОЛО НА ОДНОМ ЭКРАНЕ** — если телефон не подключился: всё управление стрелками и `Enter` прямо с пульта ТВ.
- Если Wi-Fi режет синхронизацию — раздайте мобильную точку доступа (игре нужен лишь лёгкий трафик: карта и открытые сети MQTT). Игра работает и в двух вкладках одного устройства.
- Кнопка «НОВАЯ ИГРА» в «Меню» телефона создаёт новую комнату с чистым счётом.

## Как устроена игра

| Акт | Содержание |
| --- | --- |
| Акт 1 · Тихая ночь | Сцена: 109 из 189 ячеек вскрыты, сигнализация молчала — рождается «доска версий» |
| Акт 2 · Люди вокруг хранилища | Подозреваемые: персонал, конкуренты, «Король Ключей», итальянец с офисом |
| Акт 3 · Десять слоёв | Реконструкция ночи: как обманули каждый датчик (физика + логика) |
| Акт 4 · Мусор у трассы | Криминалистика: цепочка от пакета у E19 до имени |
| Акт 5 · Клетка и пустота | Арест, суд 2005 — и открытые вопросы: где алмазы, кто «Король Ключей» |
| Финал | Доска версий: шесть версий случившегося; команда выбирает одну и ставит очки |
| Эпилог | Реальные судьбы людей и камней, документалки, источники |

В каждом акте: брифинг → свободный осмотр точек на реальной карте Антверпена → вопросы акта — на вывод, а не на память. Осмотр одной улики открывает новые следы: в акте точек больше, чем видно на старте (в списке появляется метка «новая точка»). Сквозная «доска версий»: каждая улика убивает или усиливает одну из версий, а финальная ставка — ставка очков на ту, что дожила до конца. Застряли — три уровня подсказок («Наводка → Сильная подсказка → Ответ»), без штрафа очков. Очки общие; в финале ставка удваивает верный выбор и сжигает неверный. В конце — звание команды.

## Структура

```
index.html            точка входа (выбор роли: ТВ / телефон / соло)
css/style.css         нуар-архив: тема, типографика
js/data.js            всё дело: акты, улики, документы, вопросы, версии, эпилог
js/engine.js          движок: состояние, синхронизация, рендер ТВ/телефона, очки
js/vendor/            leaflet, mqtt.js, qrcodejs (локальные копии)
fonts/                Playfair Display, PT Serif, PT Mono (кириллица, локально)
assets/img/           фотографии-иллюстрации
assets/svg/           схема хранилища (реконструкция), favicon
deploy.sh             загрузка на GitHub Pages
```

## Как работает синхронизация

ТВ и телефон обмениваются состоянием через открытые MQTT-брокеры (broker.emqx.io → broker.hivemq.com → test.mosquitto.org, подключаются по очереди). Комната — 5-символьный код в адресе и топике. Между вкладками одного устройства работает и BroadcastChannel. Никакой регистрации и серверов своего — только GitHub Pages.
